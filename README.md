# LogiTrack

LogiTrack is an academic team project developed as part of my Software Engineering studies at Universidad Fidélitas.

The project is a Java desktop application focused on logistics management and was created to apply concepts such as data structures, object-oriented programming, recursive search, graphical user interfaces, and JSON persistence.

## Features

- Distribution center management
- Package management
- Dispatch queues
- Delivery history
- Recursive search
- JSON data persistence
- Java Swing graphical user interface

## Data Structures

- Singly linked lists
- Doubly linked lists
- Queues
- Stacks

## Technologies

- Java
- Java Swing
- Maven
- JSON
- NetBeans

## Project Type

Academic team project — Software Engineering coursework.

## Project Status

Core administrator functionality implemented.  
The client module remains under development.
